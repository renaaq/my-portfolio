# Portfolio Personal - Base

Aplicacion full-stack base para un portfolio personal de desarrollador con Node.js, Express, PostgreSQL y vistas EJS.

## Requisitos

- Node.js 18 o superior (recomendado: Node.js 20 LTS).
- npm 9 o superior.
- PostgreSQL instalado localmente (o acceso a una instancia remota).

## Comandos

```bash
npm install
npm run dev
```

## Variables de entorno

Copiar `.env.example` a `.env` y ajustar valores:

- `PORT=3000`
- `DATABASE_URL=postgresql://usuario:password@localhost:5432/portfolio_db`
